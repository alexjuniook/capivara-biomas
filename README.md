# Capivara — Jornada pelos Biomas

Versão estática preparada para hospedagem no Cloudflare Pages.

## Publicação
- Sem etapa de build: HTML, CSS e JavaScript estão incorporados em `index.html`.
- Diretório de saída: `.`
- Entrada: `index.html`

## Compatibilidade
O jogo usa Canvas 2D, CSS, JavaScript nativo e armazenamento local do navegador. Não depende de Google Apps Script nem de serviços pagos externos.

## Observação
A versão original e modular permanece no repositório [ketin](https://github.com/alexjuniook/ketin), na pasta `Capivara-Jornada-pelos-Biomas`. Este repositório é uma cópia isolada para a implantação Pages.
